## 📚 LibraryManagment System

A C# Windows Forms application with SQL Server database, following a 3-Tier Architecture:

### 🔧 Technologies Used
- Visual Studio
- C#
- Windows Forms
- SQL Server
- ADO.NET

### 🧱 Project Structure (3-Tier)
- **Presentation Layer**: `LibraryManagment`  
  → This is the main project with the UI.
- **Business Logic Layer (BLL)**: `LibraryManagment_business`  
  → Contains all business logic.
- **Data Access Layer (DAL)**: `LibraryManagment_Data`  
  → Handles database operations.
